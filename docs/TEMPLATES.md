# History Templates & Card Examples

Ready-made cards for the history entities created by **PSB History Engine**.
Each card comes in two versions with the same look: 

| **PSB** repository | **CB** repository |
| :--- | :--- |
| [Piotras Smart Button](https://github.com/Piotras1/piotras-smart-button) |  [Custom Button-card](https://github.com/custom-cards/button-card) |

---

## Temperature
### What the cards do
All cards show the current value, a status text with a color picked from thresholds you define, and a filled history chart

| [PSB version](URL_TEMPERATURE_PSB) | [CB version](URL_TEMPERATURE_CB) |
| :--- | :--- |
| <img src="../img/piotras-smart-button-temp.jpg" alt="Temperature PSB card"> | <img src="../img/custom-button-card-temp.jpg" alt="Temperature CB card">  |
| Tap the underlined `-N pts` label to switch the time range<br>Tap the chart to open the more-info dialog of the history entity<br>Tap anywhere else on the card to open the source sensor | Tap the card to open the more-info dialog of the source sensor |
